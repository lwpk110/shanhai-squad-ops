## EP1《闻鸡起舞》制作计划（山海小队版 · 深度版）

**深意内核（三层递进，层层埋转发点）**
1. 闻鸡起舞≠早起：祖逖练的不是剑，是"天下大乱，我要做点什么"的志向。没有"值得起来的事"，闹钟响十遍也没用。
2. 自律需要"刘琨"：一个人早起一天容易，难的是有人陪你早起三年。给孩子找个搭子，比买十个闹钟管用。
3. 给家长的一句话：别只催"快起床"，先帮孩子找到"为什么起床"。鸡娃不如立志。

**选角**
- 泽泽（白泽）：说书人，开场引出 + 结尾点题
- 喔喔：客串打鸣 + 报幕
- 龙龙（青龙）：演祖逖，沉稳担当
- 虎虎（白虎）：演刘琨，赖床担当（笑点）

**结构（竖屏 9:16，约 60 秒）**

| 段 | 内容 | 时长 |
|---|------|------|
| 1 | 片头：水墨"山海小队"logo，喔喔举旗"开演啦！" | 3s |
| 2 | 钩子（反常识）："闻鸡起舞最打动人的，不是早起。" | 3s |
| 3 | 泽泽说书：西晋末年天下大乱 → 祖逖立志 → 喔喔打鸣 → 龙龙叫醒赖床的虎虎 → 晨练 | 22s |
| 4 | 古今对照蒙太奇：古代练剑 ↔ 现代孩子早起读书（水墨转场） | 8s |
| 5 | 泽泽点题三层：志向 / 搭子 / 为什么 | 12s |
| 6 | #闻鸡起舞7天挑战 + 互动提问 | 7s |

**旁白文案（深度版 · 关键句）**
- 钩子："闻鸡起舞，最打动人的不是早起。"
- 泽泽："西晋末年，天下大乱。祖逖心里装着一件事：我要练好剑，报效国家。"
- 喔喔："喔喔喔——！"
- 龙龙："虎虎，起床练剑！" / 虎虎："再睡一会儿嘛……" / 龙龙："说好一起练的，走！"
- 旁白："鸡叫了三遍，他们练了三年。祖逖练的不是剑，是心里的那件事。"
- 古今对照："一千七百年前，他们闻鸡起舞；今天，你为什么早起？"
- 泽泽点题："第一，有值得起来的事，闹钟才叫得醒你。第二，找个刘琨吧，自律需要搭子。第三——"（看向镜头）"别只催孩子早起，先帮他找到为什么。"
- 挑战："#闻鸡起舞7天挑战：每天早起10分钟，做一件小事，评论区打卡，第七天见！"
- 互动："你心中那件'值得早起的事'是什么？"

**蹭流量打法**
- 挑战赛：#闻鸡起舞7天挑战，一条视频变 7 天连载，追更 = 涨粉
- 发布时间：早上 6:30，"闻鸡"主题配"闻鸡"时间，仪式感拉满
- 反常识标题："别再逼孩子早起了，先看看祖逖为什么起得来"（蹭鸡娃/内卷焦虑）
- 家长群转发点："给孩子找个刘琨"——一句话育儿洞察，转发率最高
- 置顶评论："你心中那件'值得早起的事'是什么？"引导 UGC
