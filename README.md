## 质量铁律（2026-10-15 EP2限流教训）

1. **画质**：严禁blur-fill，必须满幅9:16，组装后抽帧验证
2. **内容完整**：宁可80秒讲透，不60秒讲糊涂
3. **主题聚焦**：写完过"减法审查"，删掉不影响主题的一律删
4. **反批量**：每集结构20%差异化，禁连续三集套同一模子
5. **AI标识**：每集发布必勾"内容由AI生成"
6. **封面首帧**（EP6起）：9:16封面做视频第1帧持续2秒，发布时选"推荐"封面
7. **IP风格统一**（EP6起）：全片Q版定妆，组装前逐段抽帧核对

## 剧本流程

主题聚焦三段式：钩子（0-5s具象冲突）→ 完整故事（起承转合）→ 点题（三层深意+行动指令）

减法审查四问：
1. 这句删掉，主题受影响吗？（否→删）
2. 这个笑点和本集成语相关吗？（否→删/改）
3. 这个角色出场推动剧情了吗？（否→删）
4. 这段和上一集结构一样吗？（是→改20%）
