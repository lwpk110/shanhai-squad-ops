# 「山海小队讲成语」封面视觉规范 v2.0（2026-10-13 修订）

## 设计语言
水墨宣纸底 + 书法大字 + 中国结 + 朱砂印章。所有单集封面同一模板，
只换「标题 / 集数 / 主视觉」三处，保证系列一眼可认。

## 版式（1080×1920 母版 + 3:4 上传版）
**抖音封面上传规格为 3:4（官方 1242×1660）。** 生成器自动输出双版本：
母版 1080×1920（存档）+ `*_34.jpg`（1080×1440，中央 3:4 裁剪，**上传用这个**）。
母版按 3:4 安全区排布（关键内容全部落在 y=240~1680），保证 3:4 版完整。

## 制作新封面（一行命令）
```bash
cd ~/workspace/covers
# 1. 从成片抽关键帧（选最炸的一帧，避开字幕区）
ffmpeg -ss <秒数> -i <成片mp4> -frames:v 1 key.jpg
# 2. 生成封面
python3 make_cover.py <成语标题> <第N集> key.jpg cover_epN.jpg
```
关键帧截取建议：取视频中间清晰画面带（脚本自动裁掉上下模糊区与底部字幕），
优先选「角色+核心意象同框」的一帧（如虎虎举九鼎、龙龙虎虎练剑）。
